# Project documentation

The [main README](../README.md) contains setup instructions, controls, screenshots, and an explanation of the sorting process.

| Resource | Contents |

| [Final project report (PDF)](report/conveyor_sorting_report.pdf) | Published 13-page report dated 7 October 2026, stored with Git LFS. |

| [Font attribution](report/fonts/SOURCE.txt) | Provenance and hashes of the bundled Libre Baskerville fonts; the license is included alongside them. |

The published report PDF is included through Git LFS. Other generated PDFs, presentation exports, videos, and intermediate files stay in ignored local folders such as `output/`, `.presentation-build/`, and `tmp/`. The report can also be rebuilt from its source.
